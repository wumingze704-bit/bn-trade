# 00-当前目标

## 1. 目标

在币安 USDⓈ-M 永续上找到并上线一个通过样本外验证的策略。起始资金 100 USDT；是否追加资金由使用者决定。

## 2. 市场与风险包络

- 市场：币安 USDⓈ-M 永续，单向持仓，逐仓，5x 杠杆；允许做多与做空。
- 交易范围：每月选币快照 `U(R)` 中的山寨币；声明需要方向时可以交易 BTCUSDT、ETHUSDT。
- 仓位模式：`fixed_risk`，`position_frac` 0.08，`max_positions` 10；研究、最终检验、影子盘统一按 100 USDT 初始权益模拟，统计因最小下单额或取整被丢弃的仓位。
- 单笔风险 `risk_per_trade`：默认 0.015；冻结候选时在 {0.01, 0.015, 0.02} 中选定，且要求最大回撤 ≤ 25%、最差月 ≥ −12%。
- 总名义（多 + 空）≤ 权益 × 2；净敞口绝对值 ≤ 权益 × 1；中性策略多空名义相等（取整误差 ≤ 10%）。
- 风控 R5~R8：R5 日亏损 5% 停止开仓、R6 日亏损 10% 熔断、R7 连续止损 6 次暂停、R8 峰值回撤 25% 停机；研究期 R6/R8 触发后停 7 个自然日继续（`halt_mode: reset`），实盘停机后只由人工清除停机标志。

## 3. 研究与验证流程

1. 研究期滚动验证：在 `research_start`~`research_end` 上按预登记方向逐轮调参，每组参数算一次试验并登记，按滚动验证的拼接样本外曲线判定是否达标。
2. 最终检验：合格策略冻结为候选，分配一个从未被读取过的最终检验窗口（3 个自然月，`available_after` = 末日后第 3 天）；每个窗口只检验一个候选、只检验一次，判定标准事先固定。
3. 影子盘与测试网：`shadow` 模式用正式网行情记录不下单，`paper` 模式在测试网下单，通用实盘引擎三种模式共用同一份策略、组合层与执行口径。
4. 真钱实盘：只由使用者本人启动，启动参数需同时满足候选 `final=pass`、影子盘结论 `LIVE_READY`、密钥与权限检查通过。
5. 实盘监控：按 UTC 日核对持仓、止损单、权益与风控状态，异常按安全模式只平不开。
