# X4 主动买入衰竭做空（纯做空探索轨）

规格来源：`指令/自动多轮/1-自动研究循环.txt` 第八部分 X4 与 X 轨通用要求；`docs/13-研究框架.md` §10。
本文件只写假设与网格，结果在运行结束后追加。

## 假设（照抄指令，不得增删）

- 机制：过去几天主动买入占比异常高且价格已大涨的币，追涨买盘已经消耗，价格冲击随后部分回吐。
- 数据窥探披露：本方向与 R11、R12、X0~X3 同源——灵感来自 R1~R10 首次运行（已因口径缺陷作废）中
  “空头一侧净收益为正、多头一侧为负”的全研究期诊断；研究期的达标只说明“没被证伪”，
  Deflated Sharpe 的主口径包含作废的旧试验，真正的检验是最终检验窗口。X0 重跑（2026-11-27）的空头一侧
  毛盈亏 −1,005.52、资金费收入 +443.49、净 −1,050.11（−10.50%），该旧诊断在重跑后不再成立；本方向照常执行。
- 方向性、只做空；仓位模式只用 B（理由同 R11：收益来源是持续数周的供给与资金流压力，不是止损定义的
  短期信号；模式 A 的宽止损会让仓位低于最小下单额）。
- 可交易集合 = 当月 U(R) 中 30 天成交额前 30 的山寨（不含 BTC、ETH）；净敞口 ≤ 权益 × 1.5
  （只做空时总名义实际被这一条卡住，报告中写明）。
- 挤空保护与资金费过滤同 R11 通用要求：做空候选需上线 ≥ 60 天；不做空“过去 7 天平均小时化资金费
  低于当月 U(R) 10% 分位且为负”的币。
- 规则：每 24 小时调仓；主动买入占比 = 过去 D 天 `taker_buy_quote_volume` 之和 ÷ `quote_volume` 之和
  （`klines_1h_flow`，open_time 与 `klines_1h` 不一致时报错）；打分 = 截面 z(主动买入占比) +
  截面 z(过去 D 天对数收益)；取打分最高的 K 个做空。
- X4 的 shuffle 适用（打分决定选币）：按 g 款用 20 个种子打乱标的、保留方向与止损，要求全部种子的
  年化夏普低于 base；delay1 ≤ base + 0.30；另按 l 款与 X0（N = 20 组）比较，要求扣除 X0 后的超额
  年化夏普 ≥ 0.6；试验照常登记 `kind=tuning` 并计入 `trials_used` 与 Deflated Sharpe；全部指标与情景
  照常计算；不写入 `qualified_pool`、不冻结、不进入最终检验；本轨不做一次修订。

## 诊断与结论

- 主动买入衰竭方向同样**被成本吃光**：空头毛 +1,652.31、成本 3,084.43（成本/毛收益 1.867）、
  资金费 −423.00，净 −1,009.12（−9.78%）。交易 3,068 笔、换手 616.9 倍权益 —— 每日调仓的前 K 名
  变化极快，是四轮里换手最高的方向。
- shuffle 20 个种子全部低于 base（最高 −0.2273），说明“主动买入占比 + 涨幅”确实含有信息（h、g 通过），
  但信息强度不足以覆盖 1.9 倍毛收益的交易成本。
- delay1 显著更差（−63.10%、夏普 −0.7768）：与 X2、X3 相反，本方向的信号在下一周期就衰减，
  说明“主动买入衰竭”只在当日有效。
- 第 1 折 +31.05%（训练夏普 −0.2838，选中参数是 D=1/K=3）与其余各折的负收益反差极大，分折不稳。
- l 款：扣除 X0 后超额夏普 −0.0758（要求 ≥ 0.6）。
- 结论：**不赚钱**，方向 `reported_fail`；不修订（X 轨不做修订）。
