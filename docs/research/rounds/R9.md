# R9 BTC 对冲的单边动量（btc_hedged_momentum）

## 假设（先写后跑）

- 经济机制：山寨币的横截面动量里同时混着“相对强弱”与“对 BTC 的 beta”。只做多或用对称多空时，
  beta 会随行情变化主导收益（R1 的多头端 −39.9、空头端 +18.3 就是这种混合的结果）。用 BTC 反向头寸
  把市场方向对冲掉，只留下相对强弱；再按 BTC 中期趋势决定做多强势组还是做空弱势组，因为动量收益在
  上涨与下跌阶段分布在不同的腿（上涨期强势币延续、下跌期弱势币补跌）。
- 预期收益来源：山寨对 BTC 的相对强弱（alpha），扣除 BTC 对冲成本与资金费。
- 可能失效的情形：山寨与 BTC 同涨同跌（对冲后无收益）；BTC 趋势判错导致站错边；对冲比例与仓位取整不匹配。
- 打分：山寨动量 = 过去 L 天对数收益 ÷（1h 收益标准差 × √窗口小时数），截止决策前 4 小时。
- 方向：BTC 过去 T 天对数收益 > 0 → 做多动量最高的 K 个山寨、用 BTC 空头对冲；< 0 → 做空最低的 K 个、
  用 BTC 多头对冲。对冲权重 = `hedge_weight`（网格固定 1.0，即与风控名义同量级）。
- 止损：山寨与 BTC 都用 3 × ATR14(4h)，≤ 15%。
- 网格（4 组，≤10）：`K ∈ {3, 5}` × `T ∈ {50, 100}` 天；`L = 28` 天、调仓 168 小时固定。
- 选参：每折用折前全部数据按年化夏普选参（训练期交易数 ≥ 30，并列取交易数少的）。
- 数据：研究期 2021-02-01 ~ 2026-07-31；U(R) 为 `data/universe_hist/`。

## 诊断

- 对冲没有解决方向问题：多头腿（BTC 上涨期做多强势山寨）净 −19.05 USDT，空头腿（BTC 下跌期做空弱势
  山寨）净 +5.30 USDT；前两折合计 −13.3%，第 3 折起无交易。
- 单参数诊断（同一框架、同一数据，T50 K5）：全期 185 笔交易，权益峰值 129.2；2022-08-19 权益从峰值回撤
  20%，触发 R8 `flatten_all`，`halt_mode: strict` 后不再交易（最后一次平仓 2022-08-19 21:00 UTC）。
- 训练夏普为正（第 1 折 1.133）但样本外为负，说明“BTC 趋势 + 山寨相对强弱”在 2022 年的两次下跌中
  站错边：BTC 趋势判多后山寨补跌、对冲不足。
- 成本不是主因（成本 / 毛收益 0.092、换手 18.8）：方向错误是主因。
- `nohalt` 情景 +32.31%、`short_only` +11.23%，说明不设停机时该方向在 2024 年之后有一段正收益，
  但这是风控禁止的路径，不能作为达标依据；base 在第 2~3 折已被停机截断。

## 判定

未达标项：年化夏普 ≥ 1.0、5 折至少 4 折为正、bootstrap 下限 > 0、Deflated Sharpe ≥ 0.80、
cost2x 净收益 > 0。

**判定：FAILED（首次网格）**。不做修订：方向由 BTC 趋势规则固定，把趋势判据换掉或把对冲比例调大
都属于按结果挑选；网格已覆盖 K 与趋势窗口。保留 4 次试验记录，进入 R10。
