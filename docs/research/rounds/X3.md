# X3 永续持续溢价做空（纯做空探索轨）

规格来源：`指令/自动多轮/1-自动研究循环.txt` 第八部分 X3 与 X 轨通用要求；`docs/13-研究框架.md` §10。
本文件只写假设与网格，结果在运行结束后追加。

## 假设（照抄指令，不得增删）

- 机制：永续价格持续高于指数价格（溢价指数为正）说明杠杆多头需求过剩；溢价向 0 回归与随后的正资金费
  都对空头有利。
- 数据窥探披露：本方向与 R11、R12、X0~X2 同源——灵感来自 R1~R10 首次运行（已因口径缺陷作废）中
  “空头一侧净收益为正、多头一侧为负”的全研究期诊断；研究期的达标只说明“没被证伪”，
  Deflated Sharpe 的主口径包含作废的旧试验，真正的检验是最终检验窗口。X0 重跑（2026-11-27）的空头一侧
  毛盈亏 −1,005.52、资金费收入 +443.49、净 −1,050.11（−10.50%），该旧诊断在重跑后不再成立；本方向照常执行。
- 方向性、只做空；仓位模式只用 B（理由同 R11：收益来源是持续数周的供给与资金流压力，不是止损定义的
  短期信号；模式 A 的宽止损会让仓位低于最小下单额）。
- 可交易集合 = 当月 U(R) 中 30 天成交额前 30 的山寨（不含 BTC、ETH）；净敞口 ≤ 权益 × 1.5
  （只做空时总名义实际被这一条卡住，报告中写明）。
- 挤空保护与资金费过滤同 R11 通用要求：做空候选需上线 ≥ 60 天；不做空“过去 7 天平均小时化资金费
  低于当月 U(R) 10% 分位且为负”的币。
- 规则：每 24 小时调仓；打分 = 过去 W 小时 `premium_1h` 收盘值的平均；取打分 > 0 且最高的 K 个做空；
  溢价数据缺失的币不参与打分（不按 0 计）。
- X3 的 shuffle 适用（打分决定选币）：按 g 款用 20 个种子打乱标的、保留方向与止损，要求全部种子的
  年化夏普低于 base；delay1 ≤ base + 0.30；另按 l 款与 X0（N = 20 组）比较，要求扣除 X0 后的超额
  年化夏普 ≥ 0.6；试验照常登记 `kind=tuning` 并计入 `trials_used` 与 Deflated Sharpe；全部指标与情景
  照常计算；不写入 `qualified_pool`、不冻结、不进入最终检验；本轨不做一次修订。

## 诊断与结论

- 溢价指数做空不赚钱：空头毛 −1,586.35、资金费净支出 −1,080.67、成本 817.78，净 −1,323.46（−13.23%）。
  溢价为正说明多头付资金费，但“溢价最高的 K 个”几乎都是已经涨完的币，持有后资金费转为净支出。
- shuffle 20 个种子中有种子夏普 +0.3186 高于 base −0.0525 —— 随机替换标的比按溢价选币更好，
  说明溢价排序没有信息（g 款不通过）。
- delay1 明显更好（+6.42%、夏普 0.1687），说明溢价信号在 24 小时内已被价格消化。
- 分折 2/5 为正、2023 −22.00%、2026 −17.53%，正收益集中在 2025（+45.30%）。
- 结论：**不赚钱**，溢价指数方向 `reported_fail`；不修订（X 轨不做修订）。
