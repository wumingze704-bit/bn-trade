# R5 组合（ensemble）

## 假设（先写后跑）

- 经济机制：动量、资金费拥挤与短期反转三个方向的收益来源不同、相关性较低，等权合成可以降低单一
  风格失效时的回撤。
- 成分事先固定：R1 取 L14 K3，R2 取 D1 K3，R4 取 L3 K5（各自首轮网格在全研究期按年化夏普、
  交易数 ≥ 30 选出的参数）；打分做截面 z 分数后等权相加，不拟合权重、不按结果筛选成分。
- 网格（4 组）：合成后 `K ∈ {3, 5}` × 调仓 `{8h, 24h}`；止损 3 × ATR14(4h) ≤ 15%。
- 数据：研究期 2021-02-01 ~ 2026-07-31。

## 结果（首次网格，4 组）

拼接曲线（5 折，2022-02-01 ~ 2026-08-01）：

| 指标 | 数值 |
| :--- | ---: |
| 年化夏普 | −1.078 |
| 最大回撤 | 19.4% |
| 交易数 | 391 |
| 换手（名义 / 初始权益） | 54.8 |
| 成本 / 毛收益 | 0.186 |
| 资金费收支 | +1.96 USDT |
| 多头净收益 | −17.87 USDT |
| 空头净收益 | −2.21 USDT |
| Deflated Sharpe | 0.0004 |

分折：第 1 折选中 K3 24h（训练夏普 0.423，折内 −19.24%，391 笔）；第 2~5 折仍选该组，
但停机后无交易（0 笔）。其余三组（K3 8h、K5 8h、K5 24h）自身拼接日频夏普为 −0.0704、0.0、−0.0334。

情景：base −1.066、cost2x −1.162、delay1 0 笔、long_only −0.384、short_only −0.310、
nohalt −0.667、shuffle −0.710。

## 诊断

- 合成没有降低回撤之外的收益：等权相加把 R1/R2/R4 的负收益叠加，第 1 折即亏 19%，随后触发 R8。
- 成分本身全部不达标（R1 −0.470、R2 −0.607、R4 −0.939），组合无法把负期望变成正期望。
- 丢弃仓位与最小下单额约束仍存在；资金费合计转为 +1.96 USDT，主要来自合成后的空头。

## 判定

**判定：FAILED（首次网格）**。不做修订：成分固定、网格只有 K 与调仓，已全部覆盖；改成分等于按结果
筛选，不符合第七部分第 6 条。保留 4 次试验记录。
