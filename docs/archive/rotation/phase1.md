# phase1：轮动策略调参期（M1~M12）结论与冻结文件

结论：PASS

- 评估区间：M2 起点 2024-11-01 ~ M12 末尾 2025-10-01（M1 与 30 天预热只用于打分与均线预热）。
- 冻结配置：`configs/rotation_frozen.yaml` + `configs/sizing.yaml`（`fixed_risk`、`position_frac=0.08`、`risk_per_trade=0.01`、`leverage=5`、`max_positions=5`）。
- 试验预算：26 组，实际使用 25 组（第 1 轮 12 + 第 2 轮 7 + 第 3 轮 6）。
- 全部数字来自 `artifacts/reports/rotation/<run_id>/summary.json` 的实际运行输出。

## 4. 泄露检查

触发条件：任一组试验出现“月化收益 > 20%”或“年化夏普 > 3”。全部 25 组的最高月收益为 **+14.06%（2025-07，冻结配置）**、最高年化夏普为 **1.647**，均未触发；四项检查中三项已作为常规情景跑出，结果见下。

| 检查项                                   | 冻结配置结果                                             | 判定 |
| :--------------------------------------- | :------------------------------------------------------- | :--- |
| 信号整体延后一个调仓周期（`delay1`）     | 夏普 1.162、净收益 +16.97%、回撤 12.96%、最差月 −6.45%   | 仍为正，说明信号不是靠“当根 K 线” |
| 成本 × 2（`cost2x`）                     | 夏普 1.389、净收益 +20.95%、回撤 11.06%                  | 净收益仍为正                     |
| 打分随机打乱（`shuffle`，种子 42）       | 夏普 −0.142、净收益 −3.70%、780 笔                        | 接近 0 且为负，符合“打乱后无 alpha” |
| 逐行检查打分与过滤是否用到调仓时刻之后的数据 | 打分最后一根 1h K 线在 `t − score_lag_hours` 收盘；大盘过滤用 `t` 已收盘的最后一根 1h K 线；成交价用 `t` 之后的 1m `p_1s`；止损只用入场后的 1m `low` | 无未来数据 |

未来函数单测：`tests/rotation/test_signals.py::test_未来函数_修改调仓时刻之后的数据不改变决策` 把 `t` 及之后的小时收盘价整体改写后，过滤状态、排名与名次完全不变。
