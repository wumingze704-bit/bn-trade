# 10 可视化看板

看板只读状态库与结果文件，不调用币安 API；只监听 `127.0.0.1`，经 SSH 隧道访问。

## 1 部署与访问

- 服务：`deploy/trade-dashboard.service`，`python -m trade.dashboard --config configs/dashboard.yaml`。
- 监听地址与端口：`configs/dashboard.yaml: server.address`（只允许回环）与 `server.port`（默认 8501）。
- 电脑：`ssh -N -L 8501:127.0.0.1:8501 tokyo`，浏览器打开 `http://127.0.0.1:8501`。
- 手机：SSH App 配置同样的端口转发后访问 `http://127.0.0.1:8501`。
- 页面为深色 iOS 风格，单列自适应，手机可直接查看；首屏目标 ≤ 2 秒（2 核服务器）。

## 2 数据来源

| 数据 | 来源 |
| :-- | :-- |
| 引擎心跳、上次/下次调仓、pid 与版本 | `engine_status` |
| 持仓、挂单、事件、权益、当日成交与风控状态 | `positions`、`orders`、`events`、`equity_snapshots`、`fills`、`risk_state` |
| 调仓记录（目标、成本与估计成本） | `rebalance_log` 与最新一次 `scan_cycles` / `scan_state` |
| 一致性比对 | `consistency_log` |
| 控制标志与停机标志 | `control_flags`、`halt_flags` |
| 轮次、试验预算、候选与窗口 | `docs/research/ledger.yaml`、`docs/research/rounds/*.md` |
| 交易范围、质量、数据集与回测报告 | `data/universe/`、`artifacts/quality/`、`artifacts/reports/` |

状态库不存在时隐藏实盘页面，只保留研究页。

## 3 页面

1. **总览**：权益、今日盈亏、持仓与今日交易 4 张指标卡；最新一次调仓目标与过滤结果；权益曲线；当前持仓、挂单与最近事件。
2. **持仓**：方向、数量、入场价、止损价与交易所止损状态（缺失或方向异常标红）。
3. **调仓记录**：每次调仓的时间、权益、多空名义、实际成本与估计成本（bp）、目标数与成交笔数，并展示目标仓位明细。
4. **一致性**：shadow 与离线回放、live 与 shadow 的一致率与明细。
5. **研究**：两个标签页。「轮次与窗口」展示试验预算、轮次结论、候选与最终检验窗口；「数据与模型」展示月度交易范围快照、数据质量与数据集清单。
6. **控制**：暂停开仓、恢复开仓、调整 `risk_per_trade`（0.005 ~ 0.01）、请求全部平仓；全部操作需要 PIN 二次确认。

## 4 控制与安全

- 所有控制操作经 `trade.live.control` 写状态库标志，由引擎下一轮巡检读取；看板不直接调用交易所。
- PIN 来自环境变量 `control.pin_env`（默认 `DASHBOARD_CONTROL_PIN`）；未设置时读 `control.pin_file`（默认 `./.dashboard_pin`，权限 600，不进入 git）。

- 连续失败 `control.max_pin_failures` 次后锁定 `control.lock_minutes` 分钟。
- 所有写请求校验 `Host` 与 `Origin`，只接受本机来源。
- 看板不提供清除停机标志、切换运行模式的功能；停机后只能在服务器人工执行 `live_runner.py --clear-halt`。
- 控制关闭（`control.enabled: false`）时整个控制页只读。

## 5 盈亏遮蔽

`configs/live.yaml: engine.hide_pnl_until_final` 为 true 时，若候选 `final` 为 `pending` / `running` 且引擎模式为 `shadow` / `paper`，总览与权益接口不返回虚拟权益与收益，页面提示“盈亏遮蔽中”；只展示持仓、调仓与一致性等运行数据。

## 6 接口

| 方法 | 路径 | 说明 |
| :-- | :-- | :-- |
| GET | `/api/status` | 顶栏状态（状态库可用性、心跳、停机与安全模式） |
| GET | `/api/overview?candidate=` | 指标卡、持仓、挂单与事件（支持盈亏遮蔽） |
| GET | `/api/equity?range=&candidate=` | 权益曲线（支持盈亏遮蔽） |
| GET | `/api/scan` | 最新一次调仓的目标与过滤结果 |
| GET | `/api/engine` | 引擎心跳列表与总账摘要 |
| GET | `/api/rebalances?candidate=` | 调仓记录 |
| GET | `/api/consistency?candidate=` | 一致性比对 |
| GET | `/api/control?candidate=` | 控制状态与停机标志 |
| POST | `/api/control` | 控制操作（PIN） |
| GET | `/api/positions` / `/api/orders` / `/api/events` | 持仓 / 挂单 / 事件 |
| GET | `/api/universe` / `/api/quality` / `/api/datasets` | 研究页数据 |
| GET | `/api/reports` / `/api/reports/{run_id}` | 回测报告 |
| WS | `/ws` | 每 5 秒推送 `/api/status` |

## 7 配置

`configs/dashboard.yaml` 字段与 `trade.dashboard.config.DashboardConfig` 一一对应：`server`（监听地址与端口）、`paths`（状态库、交接文件、研究数据与报告目录）、`push_sec`、`cache_sec`、`display`、`control`（`pin_env`、`pin_file`、失败次数与锁定时长）。未知字段报错。
