- 东京服务器只读核查 LUNAUSDT、FTTUSDT 的日线、1m K 线和 aggTrades 示例对象；全部 6 个 HEAD 请求返回 HTTP 200。
- 从公开 S3 月度 K 线前缀枚举 900 个 USDT 后缀目录，当前 `exchangeInfo` 返回 522 个 USDT 永续。归档目录名完整清单位于 [20261031-T0.14-archive-symbols.jsonl](20261031-T0.14-archive-symbols.jsonl)；这是归档目录清单，不把差集冒充已下架永续的最终分类。
- 实现 `assemble_bars`、`write_monthly_bars` 和 CLI 接线：K 线、逐笔原子量、5 分钟滞后对齐的 OI、已结算 fundingRate 合为月 parquet；缺 K 线与缺逐笔分列记录，任一缺失都置 `is_filled=1`。
- 实现 PyArrow 32 MiB 流式四列读取、Numba 分钟汇总、纯 Python 参考版、单遍精确 p99；缺失前日 p99 不再回退到当日阈值，缺日/阈值来源写入审计数据。
- 实现按币和窗口终点计算质量结论及原子 parquet 缓存，报告 K 线缺失率、逐笔缺失率、一致性误差、源文件缺失日和 p99 缺失诊断。
- 东京服务器下载单次测速：1000PEPEUSDT 38,202,242 B / 2.262 s（16.888 MB/s）；TLMUSDT 528,854 B / 0.043 s（12.288 MB/s）。这是下载吞吐，不是解析性能或持续带宽。
