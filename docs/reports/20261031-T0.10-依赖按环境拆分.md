## 1. 做了什么

1. **pyproject.toml 按环境拆分**：基础依赖保留双端共用的 `httpx/numba/numpy/pandas/pyarrow/pydantic/PyYAML/scipy/websockets`；新增 `research`（`lightgbm`、`matplotlib`、`plotly`、`torch==2.14.1+cu126`）、`live`（`fastapi==0.162.0`、`uvicorn==0.54.0`、`binance-sdk-derivatives-trading-usds-futures==18.2.0`、`torch==2.14.1`）、`dev`（mypy/pip-tools/pytest/ruff/types-PyYAML）。删除 `streamlit` 与 live 侧的 `plotly` Python 包（看板改用本地化 Plotly.js）。
2. **生成三把哈希锁文件**（均 `--generate-hashes`）：`requirements-base.lock`（共享核心）、`requirements-research.lock`（CUDA 12.6 torch，经 PyTorch cu126 索引解析 `torch==2.14.1+cu126`）、`requirements-live.lock`（CPU torch，按 Linux `manylinux_2_28_x86_64` 目标平台解析 `torch==2.14.1`）。三把锁均以 `--allow-unsafe` 锁定 setuptools，避免 torch 的 `setuptools>=77.0.3` 依赖在 `--require-hashes` 下被拒绝。
3. **币安 SDK 核实**：包名与版本经 PyPI 官方仓库核实为 `binance-sdk-derivatives-trading-usds-futures` 18.2.0（与 02 §4 既有的包名一致），未引入非官方依赖。developers.binance.com 页面有 Cloudflare 校验无法直读，已注明。
4. **删除旧 `requirements.lock`**：在新锁文件与 README/02 引用全部迁移后删除。
5. **同步文档**：README、02 §4/§5.2/§6、AGENTS.md §3.2、docs/tasks.md、docs/design.md 变更记录。

## 5. 与设计的偏差

1. 币安 SDK 版本经 PyPI 官方仓库核实为 18.2.0（02 §4 既有包名一致）；developers.binance.com 页面有 Cloudflare 校验无法直读，未据此猜测版本，也未引入非官方依赖。
